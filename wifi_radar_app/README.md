# Wi-Fi Радар — Система обнаружения движения

Flutter-приложение для обнаружения движения людей через изменения Wi-Fi сигнала (RSSI-сенсинг).

## Как это работает

Тело человека поглощает и отражает радиоволны 2.4/5 ГГц. Когда человек движется, уровень сигнала Wi-Fi (RSSI) меняется характерным образом. Приложение:

1. Непрерывно сканирует все видимые точки доступа Wi-Fi
2. Собирает историю изменений RSSI каждые 1.5 секунды
3. Вычисляет дисперсию сигнала — высокая дисперсия = движение
4. Отображает обнаруженные объекты на радарном экране

## Возможности

- Радарный интерфейс (360°) с разверткой в реальном времени
- 5 уровней тревоги: ЧИСТО / СЛАБО / ДВИЖЕНИЕ / АКТИВНО / ТРЕВОГА
- Отображение силуэтов обнаруженных тел
- Оценка расстояния по силе сигнала
- Демо-режим (без реального Wi-Fi)

## Установка и запуск

### Требования
- Flutter 3.16+ 
- Android 5.0+ (API 21+)
- Разрешения: ACCESS_FINE_LOCATION + ACCESS_WIFI_STATE

### Сборка
```bash
cd wifi_radar_app
flutter pub get
flutter run --release
```

### Android разрешения
Приложение запрашивает разрешение на местоположение при запуске — это обязательно для сканирования Wi-Fi на Android 6+.

## Ограничения технологии

| Возможность | Статус |
|---|---|
| Обнаружение движения | ✅ Работает |
| Обнаружение присутствия | ✅ Работает |  
| Примерное расстояние | ⚠️ Ограниченная точность |
| Силуэт тела | ❌ Невозможно с Wi-Fi RSSI |
| Инфракрасное зрение | ❌ Требует IR-камеру |
| Сквозь несколько стен | ⚠️ Зависит от материала |

## Дальнейшее развитие

Для более точного обнаружения нужны:
- CSI (Channel State Information) — требует root/специальный драйвер
- UWB радар (Ultra-Wideband) — отдельное железо
- mmWave радар (60 GHz) — модуль типа TI IWR1443
